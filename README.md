# Setup Dev

To launch mkdocs locally, follow these instructions:

1. Create a Python environment:
   ```bash
   python3.11 -m venv .venv
   source .venv/bin/activate
   ```

2. **Install Dependencies**
   ```bash
   make install
   ```

3. Start the serving endpoint:
```bash
make serve
```
